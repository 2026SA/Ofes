# OFES Ver.1.11

## 主な変更

### 1. 会場案内の時間帯表示を短く整理

会場案内の見出しを **「表示する時間帯（セッション）」** に変更しました。

ボタンの表示は次の形です。

- 現在
- ① 09:20〜09:40
- ② 09:50〜10:10
- ③ 10:20〜10:40
- ④ 10:50〜11:10

スクリーンリーダー用の aria-label には「セッション①」など正式名称を残しています。

### 2. 管理者画面にデモデータ登録を追加

「プログラム」タブに以下を追加しました。

- **デモデータを登録**
- **デモデータを削除**

登録済み会場を利用して、セッション①〜④と午後のサンプル発表を下書きに追加します。

- 会場登録そのものは変更しません。
- 既存の本番プログラムも削除しません。
- `demo-` で始まるデモ用プログラムだけを追加・削除します。
- 別ブラウザ・シークレットウィンドウで確認する場合は、デモ登録後に「データ保存」→「Firestoreへ公開」を行ってください。
- 確認後は「デモデータを削除」→再度「Firestoreへ公開」でデモを消せます。

### 3. リアクションの「全クリア」と復元ポイント

管理者画面の「リアクション集計」に以下を追加しました。

- **全リアクションをクリア**
- **最新の復元ポイントから復元**

全クリア時は、最初に確認メッセージを表示します。

1. 現在のリアクションをFirestore上の復元ポイントへコピー
2. 復元ポイントの保存が成功したことを確認
3. その後に現在のリアクションを全削除

復元ポイントの保存に失敗した場合は、全クリアを実行しません。

復元ポイントは複数回分保存され、画面からは最新のものを復元できます。復元すると、その時点のリアクション状態に戻ります。

## Firestore Security Rulesについて

**Ver.1.11ではRulesの更新が必要です。**

理由：

- 管理者による全リアクション削除
- 管理者による復元
- `reactionBackups` への復元ポイント保存

同梱の `firestore.rules` をFirebase Consoleの「Firestore → ルール」に貼り付けて公開してください。

## 既存データの互換性

- 会場
- 会場ID
- セッション
- プログラム
- Firestore公開データ

は従来形式を維持しています。

更新前に「データ保存」から設定JSONを書き出しておくことを推奨します。

## リアクション機能

午前は **会場案内 → 教室 → 各発表カード**、午後のリアクション対象行事は **プログラム画面** から送信します。

アイコンは次の5種類です。

- 👍 よかった
- 💡 なるほど
- ✨ すごい
- 😊 楽しかった
- 🙌 応援したい

管理者は全発表の一括集計、学年別PDF出力、個別CSV保存ができます。
