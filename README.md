管理画面からは変更できません。

## Firebase
はい、他のアプリと同様にFirebaseを使えば、ポスター画像のアップロードが可能です。

この試作品では、
- Firestore：OFES全体設定
- Firebase Storage：ポスター画像
を使う設計を入れています。

### 設定方法
`firebase-config.js` に Firebase Console のWebアプリ設定を貼り付けます。

設定済みの場合：
- 管理者画面でポスター画像を選択
- Firebase Storageへアップロード
- ダウンロードURLを取得
- Firestoreの設定へ保存
- 来場者側にも共有

未設定の場合：
- localStorageで試作動作

## Firebaseのセキュリティ
アプリ内の固定パスワードは「管理画面を誤操作しないための入口」です。
Firebaseへの書き込みを本番で安全に制限するには、Firebase Authenticationや適切なSecurity Rulesを併用してください。

## GitHub Pages
ZIPを展開し、OFESリポジトリ直下にアップロードしてください。
Firebaseを使う場合は、GitHub PagesのドメインをFirebase Authentication等の許可ドメインに追加する場合があります。
