# OFES Ver.1.2 — 会場案内の全体表示・新ロゴ

## 今回の変更
- 学校全体図と前期棟1Fについて、**初期表示（100%）で図面が完全に収まる**よう、スマートフォンの表示幅・高さに応じて自動調整。
- ほかの図面も初期表示時の内側の高さ制限を廃止。図面内にスクロールバーを出さず全体像を表示。
- + / − / 戻す、およびピンチ拡大はそのまま。**拡大した時に限り**図面内スクロールを有効化。
- 提供された新しい OFES ロゴ画像をヘッダーとブラウザのアイコンに設定。周囲の余白を切り抜いて小さな画面でも見やすくしただけで、文字や色・図形は変えていません。
- **保存データ形式とlocalStorageキーはVer.0.8〜Ver.1.1から変更していません。** 会場IDと図面SVGも同一です。
- Firebase GoogleログインとFirestore読み取り確認は引き続き可能。**Firestoreへの保存処理はまだ実装されていません。**

## 教室登録の継続について（重要）
- 同じブラウザ・同じ公開オリジン（例：`https://2026sa.github.io`）でGitHub Pagesのアプリを上書きした場合、通常は教室位置・名称・プログラム・年度設定を自動的に引き継ぎます。
- ブラウザの保存データ消去、プライベートブラウザ、サイトURL変更、端末変更、不具合によるデータ破損があれば失われる可能性があります。
- **必ず管理者画面→「データ保存」→「設定JSONを書き出す」からバックアップを保存してください。**
- バックアップ復元は「設定JSONを読み込む」。復元時は現在の設定データを上書きします。
- 教室の位置と名称を大量に登録する場合は、できればFireStoreへのクラウド保存機能が完成してから行うか、都度バックアップを取りながら進めてください。

## 公開
ZIPを解凍し、中身（index.html、app.js、style.css、firebase-bridge.js、firebase-config.js、assets/）をGitHubのOFESリポジトリにアップロードして更新します。以前のロゴSVGは今回の版では使用しません。ブラウザ更新時に古い画面が残る場合は強制再読み込みしてください。

## Firebaseと安全性
- Firestoreルールを今回の画面修正に合わせて変更する必要はありません。
- Googleログイン済みでも保存はローカルだけです。管理画面パスワードは本番用の編集認可ではありません。
- 公開時に児童生徒の個人情報・校内の非公開情報を含めないでください。
