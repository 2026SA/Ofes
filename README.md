# OFES Ver.1.9

## 主な変更

- 午前（セッション①〜④）のリアクションは、**会場案内 → 教室 → 各発表カード**から送る方式に変更しました。
- プログラム画面では、午前の発表にリアクションボタンを表示しません。
- 午後の体育館行事は、管理画面で「午後（リアクション対象）」に設定した演目だけ、**プログラム画面**にリアクションボタンを表示します。
- リアクションの意味は画面上部にまとめて表示し、実際に押すボタンは **アイコンだけ** にしました。
  - 👍 よかった
  - 💡 なるほど
  - ✨ すごい
  - 😊 楽しかった
  - 🙌 応援したい
- 同じ学年・発表内容を複数セッションで繰り返す場合は、同じ「発表」としてリアクションを合算します。
- 管理者画面の「リアクション集計」に **全発表を一括集計** ボタンを追加しました。
- 一括集計後、**学年ごとにまとめたA4横向きの集計表**を印刷画面からPDFとして保存できます。
- 個別発表の集計・CSV保存も残しています。

## データ互換性

- 会場、会場ID、プログラム、Firestore公開データの基本形式はVer.1.8から維持しています。
- Firestore Security Rulesの変更は不要です。
- 更新前に管理画面の「下書きの設定JSONを書き出す」でバックアップを保存しておくことを推奨します。

## 午後プログラム

管理画面の「プログラム」→「開会行事・午後など、セッション以外の全体プログラム」で、区分を選べます。

- `午後（リアクション対象）`：プログラム画面にリアクションアイコンを表示
- `その他（リアクションなし）`：リアクションアイコンを表示しない

## リアクション集計PDF

管理者Googleログイン後、管理画面の「リアクション集計」で

1. 「全発表を一括集計」
2. 「集計表をPDF出力（印刷画面）」
3. ブラウザの印刷画面で「PDFとして保存」

の順に操作します。集計表は学年ごとに改ページします。
