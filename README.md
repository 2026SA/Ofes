# OFES Ver.1.12

Ver.1.11を基に、次の3点を修正しています。

1. **スマホのホーム画面アイコン**
   - `manifest.webmanifest` を追加しました。
   - iPhone用 `apple-touch-icon` と、Android/PWA用192px・512pxアイコンをOFESロゴから作成しています。
   - GitHub Pagesへ上書き後、すでにホーム画面へ追加済みの場合は一度削除して再追加すると新しいアイコンが確実に反映されます。

2. **デモデータを最大16発表へ拡張**
   - 登録済み会場のうち最大4会場を使用します。
   - セッション①〜④それぞれ最大4会場、合計最大16件の午前発表を登録します。
   - 1年生〜9年生のデモ発表を順番に配置します。
   - 本番プログラムと同じ会場・同じセッションが重なる場合は、その会場を避けます。

3. **デモ実施場所を会場案内へ即時反映**
   - 「デモデータを登録」後、この端末では下書きのデモ内容を来場者画面で即時プレビューします。
   - セッション①を自動選択し、最初のデモ会場がある棟を表示します。
   - 別ブラウザ・別スマホにも表示する場合は、従来どおり「Firestoreへ公開」が必要です。

既存の会場登録、会場ID、Firestoreデータ、リアクション、復元ポイントの形式は変更していません。Firestoreルールの変更は不要です。
