# OFES Ver.1.15

## 主な変更

- 午前のプログラム表示をセッション単位にまとめました。同じ時間帯に4会場で発表があっても、セッション①は1つの枠にまとまり、その中に各会場の発表を表示します。
- 管理者の発表登録に「発表グループ」を追加しました。例：A班、1班、合同A班。
- 「発表学年」は複数学年に対応します。例：`7年生・8年生`。
- リアクションの集計単位を「学年 + 発表グループ + 発表内容」に変更しました。同じ学年のA班・B班を別々に集計できます。
- 同じグループが同じ発表を複数セッションで行う場合は、従来どおりリアクションを合算します。
- 複数学年の合同発表は1つの集計を共有し、PDFでは該当する各学年のページに同じ行を掲載します。
- 一括集計PDFは、学年内でグループ別の行を残し、学年合計にはしません。
- PDFのリアクション列は `👍 💡 ✨ 😊 🙌` のアイコンだけにし、列幅を狭くしました。発表内容・実施時間の列を広げています。

## 入力例

- 発表学年：`7年生`
- 発表グループ：`A班`
- 発表内容：`大豊町の魅力を英語で伝えよう`

合同発表の場合：

- 発表学年：`7年生・8年生`
- 発表グループ：`合同A班`

複数学年は「7年生・8年生」のように学年数字を並べて入力してください。PDFでは7年生・8年生の両方のページに掲載されます。

## データ引き継ぎ

既存の会場、プログラム、Firestore公開データは引き継げます。旧データの発表グループは空欄として読み込まれます。必要な発表から管理画面でグループ名を追加してください。

Firestore Security Rules の変更はありません。


## Ver.1.15 追加変更

- 会場案内の「学校全体・前期棟・後期棟」の横に「プログラムに戻る」を追加しました。プログラムの「会場を見る」から移動した場合は、戻ると元のプログラム付近へ復帰します。
- 一括集計後のPDFを2種類に分けました。
  - **全体集計PDF**：全発表グループを重複なく一覧表示する教職員向け。
  - **学年別フィードバックPDF**：1つのPDF内で1学年につき1ページ。合同発表は該当する各学年ページに掲載し、児童・生徒向けの前向きなメッセージを添えます。
- 学年別PDFでも学年合計にはせず、発表グループ別の集計を維持します。
