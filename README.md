# OFES Ver.0.4

## 今回の修正
- ロゴの **O** を、手書き感を残しつつ **真円に近い形** に修正
- 校内マップに **校内全体図（教職員駐車場入り）** を追加
- 教室名は **前回のデータを優先** して維持
- これまでのデータを統合し、以下の地図を搭載
  - 校内全体図
  - 前期棟1F
  - 前期棟2F
  - 後期棟1F
  - 後期棟2F
  - 後期棟3F
- 体育館は校内全体図上で位置を示します
- 管理者画面から、プログラムを追加／削除／並べ替え／時刻変更／場所変更できます

## 初期管理者パスワード
`ofes2026`

## 使い方メモ
- 「MAP」は、現在開催中のプログラムがある場所を赤色で、
  このあとの場所を黄色の点線で表示します。
- 「校内全体図」では、前期課程棟・後期課程棟・体育館・駐車場をざっくり案内します。
- 個別の教室位置は、前期棟・後期棟の各階タブで確認できます。
- セッションなど同時に複数教室で行う場合は、管理者画面で同時刻のプログラムを複数作成してください。

## 保存方式
現在は試作品のため、設定は各端末のブラウザ内（localStorage）に保存されます。
管理者が編集した内容を全利用者へ自動反映するには、次段階で共有データ保存先が必要です。
