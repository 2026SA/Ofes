## MAP
登録済みの教室をプログラムの「場所」に指定すると、その時間帯に該当教室を強調表示します。

同じ時間帯に複数教室で発表する場合は、
同じ開始・終了時刻でプログラムを複数登録してください。

体育館・駐車場は選択肢にはありますが、配置図はまだありません。

## 試作品の保存方式
現在は管理画面の変更を「そのブラウザの localStorage」に保存します。
別端末へ設定を移すためにJSON書き出し／読み込みを用意しています。

本番運用で、管理者が変更した内容を来場者全員へ即時反映するには、
次の段階で共有データ保存先（Firebase / Supabase / GAS等）が必要です。
