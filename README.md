# OFES Ver.0.2（管理者画面つき試作品）

## 追加した機能
- トップ画面の「管理者」ボタン → パスワード入力 → 管理者画面
- 初期パスワード：`ofes2026`
- 管理者画面から設定可能
  - 年度・開催日・お知らせ・管理者パスワード
  - プログラムの追加／削除・開始終了時刻・会場
  - スタンプ5個のヒント・獲得メッセージ
  - 動画の追加／削除（本数可変）
  - ポスターの追加／削除（枚数可変）
- 現実の時刻に合わせて「ただいま開催中」「このあと」を自動表示
- プログラムと校内MAPを連動
  - 現在開催中の会場を強調
  - このあとの会場も表示
- Googleマップは未実装
- スタンプラリーは5個

## スタンプQRの固定URL
公開URLの末尾を以下のようにします。
- `?stamp=1`
- `?stamp=2`
- `?stamp=3`
- `?stamp=4`
- `?stamp=5`

例：`https://ユーザー名.github.io/OFES/?stamp=1`

## 重要：Ver.0.2の保存方式
この試作品では、管理者画面の変更内容をブラウザの `localStorage` に保存します。
そのため、管理者PCで保存した変更は、別のスマホやタブレットへ自動反映されません。

今回は「管理画面の操作」「可変の動画・ポスター」「時刻連動」「MAP連動」を試す版です。
実運用で全来場者へ同じ設定を配信する段階では、共有データ保存先を追加します。

## GitHub Pagesへのアップロード
ZIPを展開し、中身を既存の `OFES` リポジトリ直下へアップロードしてください。

## 校内マップについて
`images/school-map.svg` は試作用です。実際の校内配置図に差し替え可能です。
強調表示する領域は `data.js` の `places` にある `x / y / w / h`（画像に対する％）で定義しています。
