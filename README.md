# OFES Ver.1.8

Ver.1.7をベースに、来場者向け「会場案内」のセッション表示を分かりやすくしました。

## Ver.1.8 の変更点
- 会場案内の時間帯切り替えを、短縮表記ではなく「セッション①」「セッション②」「セッション③」「セッション④」と表示
- 各セッションの開始・終了時刻もこれまでどおり併記
- 教室登録、会場ID、プログラム、Firestore共有、リアクション、保護者向けお知らせPDFの仕様はVer.1.7から変更なし
- localStorageの保存キーとFirestoreのデータ構造は変更していないため、既存データを引き継げます
- Firestoreセキュリティルールの変更は不要です

更新前に設定JSONを1部保存しておくと安心です。
